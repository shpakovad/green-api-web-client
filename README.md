# Telegram Web Client

Пользовательский веб-интерфейс для отправки и получения текстовых сообщений с использованием платформы **Telegram Bot API**.

## 🚀 Стек технологий
* **React 19**
* **TypeScript**
* **Tailwind CSS v4**
* **Vite**

## 📦 Инструкция по запуску

1. Клонировать репозиторий и перейти в папку проекта:
   ```bash
   git clone <ссылка_на_ваш_репозиторий>
   cd <название_папки>
   ```

2. Установить зависимости:
   ```bash
   npm install
   ```

3. Запустить проект в режиме разработки:
   ```bash
   npm run dev
   ```

4. Открыть в браузере локальный адрес (обычно `http://localhost:5173`).

## 🧪 Как протестировать работоспособность

1. На экране входа введите **Токен вашего Telegram-бота** и ваш личный **Chat ID**.
2. левой панели приложения выберите ваш Chat ID (он добавится автоматически как дефолтный стартовый чат).
3. Напишите сообщение в поле ввода и отправьте его. Оно отобразится в окне как исходящее (синяя плашка) и мгновенно прилетит вам в Telegram от имени бота.
4. Отправьте ответное текстовое сообщение боту прямо внутри Telegram со своего телефона — в течение нескольких секунд оно автоматически отобразится на экране React-приложения (белая плашка).
